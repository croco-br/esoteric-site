Oráculo Astrológico

Três dados·Doze rodas·Uma resposta

Desde a Antiguidade, quem tinha uma dúvida que não cabia em conselho de amigo recorria às rodas do céu: uma para os planetas, uma para os signos, uma para os números. Este oráculo conserva o rito. Escreva o que lhe pesa, gire as rodas e leia a tiragem como se lê um almanaque — devagar, com atenção ao que se repete.
